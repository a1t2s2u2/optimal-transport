\begin{abstract}
\noindent
潜在拡散モデルは，autoencoder が作る潜在座標に等方的な Gaussian noise を加える．
しかし潜在座標の Euclid 構造は座標変換で変わり，decoder が表す分布の変化量とも
一般には一致しない．本稿はこの不整合を定量化し，decoder 分布を
$2$ 次 Wasserstein 距離 $W_2$ に関して等方的に拡散する
\textbf{curvature-controlled Wasserstein latent diffusion} を提案する．

対角 Gaussian decoder
$K_z=\mathcal{N}(m(z),\operatorname{diag}(\sigma(z)^2))$ に対し，
$F=(m,\sigma)$ と $G=J_F^{\mathsf T}J_F$ を定める．
通常の Euclid noise が単位時間に引き起こす decoded $W_2^2$ 変化は
$\beta\operatorname{tr}G(z)$ であり，場所と方向に依存する．
これに対し共分散 $\beta G^{-1}$ は変化率を潜在次元 $d$ にわたり
$\beta d$ に一様化し，decoder manifold の接空間上で等方的な decoded noise を
与える唯一の共分散である．さらに VAE prior $\pi$ を厳密な不変分布にもつ
座標不変な拡散 generator を構成し，その Fokker--Planck 方程式が
$(\mathcal{Z},G)$ 上の $\mathrm{KL}(\cdot\Vert\pi)$ の
Wasserstein 勾配流であることを示す．

本構成では decoder の第二基本形式 $B$ は診断量にとどまらない．
平均曲率 $\operatorname{tr}_G B$ が decoded process の It\^o drift として現れ，
$B$ の作用素ノルム $\Lambda$ が geodesic random walk の一 step における
内在距離と decoded $W_2$ の差を三次で支配する．
したがって noise covariance，drift，step size の三つが同一の
Wasserstein 幾何から決まる．最後に自然な relative score の学習目的，
matrix-free 実装，Schr\"odinger bridge への拡張，および反証可能な実験計画を与える．
\end{abstract}

\section{はじめに}
\label{sec:intro}

潜在拡散モデル（latent diffusion model; LDM）は，高次元のデータ分布を
直接拡散する代わりに，autoencoder が作る低次元表現上で diffusion model を
学習する \cite{rombach2022}．計算量と生成品質の均衡に優れる一方，
その forward process は通常，潜在空間を固定された Euclid 空間とみなし，
各座標へ同じ強さの Gaussian noise を加える．

この設計には見落とされている不整合がある．潜在変数 $z$ は観測そのものではなく，
decoder を介して初めて意味をもつ．同じ大きさの変位 $\delta z$ でも，
decoder がほとんど変化しない場所と大きく変化する場所がある．さらに潜在座標は
微分同相 $z\mapsto\psi(z)$ で取り替えられるため，座標上の「等方的」という性質は
生成モデルに固有ではない．実際，decoder の引き戻し計量による局所体積歪みが
LDM の非一様な memorization と関連することが報告されている \cite{rao2026}．

そこで本稿は，潜在コードそのものではなく，潜在コードが表す
\emph{decoder 分布}を等方的に壊すべきだ，という原理から forward process を導く．
decoder が各 $z$ に対して
\[
  K_z=\mathcal{N}\bigl(m(z),\operatorname{diag}(\sigma(z)^2)\bigr)
\]
を対応させるとする．対角 Gaussian 間では
\[
  W_2(K_z,K_{z'})^2
  =\norm{m(z)-m(z')}^2+\norm{\sigma(z)-\sigma(z')}^2
\]
が厳密に成り立つ \cite{givens1984}．したがって $F=(m,\sigma)$ とおけば，
decoder 分布の族は Euclid 空間内の部分多様体 $F(\mathcal{Z})$ として扱え，
その誘導計量は
\[
  G(z)=J_F(z)^{\mathsf T}J_F(z)
  =J_m(z)^{\mathsf T}J_m(z)+J_\sigma(z)^{\mathsf T}J_\sigma(z)
\]
になる．この $W_2$ 引き戻し計量自体は Roy and Hauberg \cite{roy2022} が
既に導入している．本稿の問いは metric を作ることではなく，
\emph{その metric から diffusion の noise，drift，離散化を一意的に設計すること}
である．

\subsection{本稿の貢献}

本稿の主な貢献は次の四点である．

\begin{enumerate}
  \item \textbf{Euclid latent noising の不整合を定量化する．}
    一般の局所共分散 $a(z,t)$ に対し，単位時間あたりの decoded $W_2^2$ 変化が
    $\operatorname{tr}(G(z)a(z,t))$ であることを示す．標準的な
    $a=\beta_tI$ では $\beta_t\operatorname{tr}G(z)$ となり，noise level の意味が
    潜在点ごとに異なる．
  \item \textbf{canonical な Wasserstein-isotropic noise を導く．}
    $a=\beta_tG^{-1}$ は decoded 変化率を $\beta_td$ に一様化し，
    decoder manifold の接空間上で共分散 $\beta_tP$ の等方 noise を与える．
    この性質をもつ潜在共分散は一意であり，潜在座標の取り替えに依存しない．
  \item \textbf{既知の VAE prior を保つ幾何学的拡散を構成する．}
    VAE prior $\pi$ に可逆な generator
    \[
      \mathcal{L}_t f
      =\frac{\beta_t}{2p_\pi}\partial_i
       \bigl(p_\pi G^{ij}\partial_jf\bigr)
    \]
    を導く．その確率法則は $(\mathcal{Z},G)$ 上の
    $\mathrm{KL}(\cdot\Vert\pi)$ の Wasserstein 勾配流である．
  \item \textbf{曲率を生成アルゴリズムの制御量にする．}
    第二基本形式の trace が decoded process の平均曲率 drift になり，
    その作用素ノルム $\Lambda$ が geodesic step と decoded $W_2$ の差を支配する．
    これにより曲率適応 step size を得る．
\end{enumerate}

一般の Riemann 多様体上の score-based model は既に存在する \cite{debortoli2022}．
本稿の新規性はその一般論ではなく，VAE decoder の確率分布が定める $W_2$ 幾何から
上記四点を同時に導き，既存の LDM が無視する semantic noising の不均一性を
直接の対象とする点にある．

\section{設定}
\label{sec:setup}

\subsection{VAE と学習対象の分布}

$\mathcal{X}=\R^n$ をデータ空間，$\mathcal{Z}\subset\R^d$ を潜在空間とする．
VAE \cite{kingma2014} の encoder を $q_\phi(z\mid x)$，decoder を
\[
  p_\theta(x\mid z)=K_z
  :=\mathcal{N}\bigl(m(z),\operatorname{diag}(\sigma(z)^2)\bigr)
\]
とする．LDM が学習すべき潜在分布は，単一の posterior ではなく aggregated posterior
\[
  \rho_{\mathrm{data}}(z)
  :=\int q_\phi(z\mid x)p_{\mathrm{data}}(x)\,\d x
\]
である．VAE prior を $\pi(\d z)=p_\pi(z)\d z$ とし，典型的には
$p_\pi=\mathcal{N}(0,I_d)$ とする．

以下，$F=(m,\sigma)\colon\mathcal{Z}\to
H:=\R^n\times(0,\infty)^n\subset\R^{2n}$ は $C^3$ 級で，
$J_F$ は全点で列 full rank と仮定する．したがって
\[
  G:=J_F^{\mathsf T}J_F
\]
は正定値であり，$M:=G^{-1}$ が定義される．境界項を無視する積分では，
$\mathcal{Z}$ に境界がないか，密度と vector field が十分速く減衰すると仮定する．

\subsection{decoder 分布の Wasserstein 幾何}

\begin{fact}[対角 Gaussian の $W_2$ \cite{givens1984}]
\label{fact:gaussian-w2}
  $K_z,K_{z'}$ に対して
  \[
    W_2(K_z,K_{z'})^2=\norm{F(z)-F(z')}^2
  \]
  が成り立つ．したがって $F$ が誘導する潜在計量は
  \[
    \langle u,v\rangle_{G(z)}
    :=u^{\mathsf T}G(z)v
    =\langle J_F(z)u,J_F(z)v\rangle
  \]
  である．
\end{fact}

$G$ の Riemann 体積要素を $\d\vol_G=\sqrt{\det G}\,\d z$ とする．
$p_\pi$ は Lebesgue 測度に関する密度なので，Riemann 体積に関する prior density は
\[
  q_\pi(z):=\frac{p_\pi(z)}{\sqrt{\det G(z)}}
\]
である．この区別は，既知の標準 Gaussian prior を不変分布として保つために重要である．

\section{Euclid noise は decoder 分布を非一様に破壊する}
\label{sec:mismatch}

一般の It\^o diffusion
\[
  \d Z_t=b(Z_t,t)\,\d t+A(Z_t,t)\,\d W_t,
  \qquad a:=AA^{\mathsf T}
  \tag{1}
\]
を考える．次の命題は forward process の局所的な「意味破壊率」を与える．

\begin{proposition}[decoded $W_2$ 二次変分]
\label{prop:qv}
  (1) のもとで，$Z_t=z$ を条件とする微小時間の変化は
  \[
    \E\!\left[
      W_2(K_{Z_{t+\d t}},K_{Z_t})^2\mid Z_t=z
    \right]
    =\operatorname{tr}\bigl(G(z)a(z,t)\bigr)\,\d t+o(\d t)
  \]
  をみたす．また decoded process $Y_t:=F(Z_t)$ の二次変分は
  \[
    \d[Y]_t=J_F(Z_t)a(Z_t,t)J_F(Z_t)^{\mathsf T}\,\d t
  \]
  である．
\end{proposition}

\begin{proof}
  事実~\ref{fact:gaussian-w2}より左辺は
  $\E[\norm{F(Z_{t+\d t})-F(Z_t)}^2\mid Z_t=z]$ である．
  It\^o の公式から $Y=F(Z)$ の martingale 部分は $J_FA\d W$ なので，
  その二次変分は $J_FaJ_F^{\mathsf T}\d t$ である．drift は二乗平均の
  $\d t$ 一次項に寄与しない．したがって
  \[
    \E[\norm{Y_{t+\d t}-Y_t}^2\mid Z_t=z]
    =\operatorname{tr}(J_FaJ_F^{\mathsf T})\d t+o(\d t)
    =\operatorname{tr}(Ga)\d t+o(\d t).
  \]
\end{proof}

標準 LDM の局所 noise covariance は $a(z,t)=\beta_tI_d$ である．
命題~\ref{prop:qv}から decoded 変化率は
\[
  \boxed{\ \beta_t\operatorname{tr}G(z)\ }
\]
となる．さらに decoded covariance $\beta_tJ_FJ_F^{\mathsf T}$ の非零固有値は
$\beta_tG$ の固有値と一致する．したがって標準 LDM は，decoder 感度の高い点を
速く壊し，感度の高い方向を強く壊す．単一の noise level $t$ が全データに対して
同じ意味をもつという通常の解釈は，一般には成立しない．

\section{Wasserstein-isotropic latent diffusion}
\label{sec:canonical}

\subsection{canonical covariance}

\begin{theorem}[decoder manifold 上で等方的な唯一の latent noise]
\label{thm:canonical}
  $P(z):=J_F(z)G(z)^{-1}J_F(z)^{\mathsf T}$ とする．これは
  $T_{F(z)}F(\mathcal{Z})=J_F(z)\R^d$ への Euclid 直交射影である．
  latent covariance を
  \[
    \boxed{\ a_*(z,t):=\beta_tG(z)^{-1}\ }
    \tag{2}
  \]
  とすると，
  \[
    J_Fa_*J_F^{\mathsf T}=\beta_tP,
    \qquad
    \operatorname{tr}(Ga_*)=\beta_td.
  \]
  したがって decoded noise は接空間上で等方的であり，decoded $W_2^2$ 変化率は
  潜在点によらず $\beta_td$ である．逆に，対称半正定値な latent covariance
  $a$ が $J_FaJ_F^{\mathsf T}=\beta_tP$ をみたすなら $a=a_*$ である．
\end{theorem}

\begin{proof}
  $P^{\mathsf T}=P$ と $P^2=P$ は $G=J_F^{\mathsf T}J_F$ から従い，
  $P$ の像は $J_F\R^d$ である．(2) を代入すれば前半を得る．
  一意性について，$J_F$ の左逆を $J_F^+:=G^{-1}J_F^{\mathsf T}$ とすると
  \[
    a=J_F^+(J_FaJ_F^{\mathsf T})(J_F^+)^{\mathsf T}
      =\beta_tJ_F^+P(J_F^+)^{\mathsf T}
      =\beta_tG^{-1}
  \]
  である．
\end{proof}

この結果は，$G^{-1}$ を heuristic な preconditioner として導入しているのではない
ことを示す．decoder 分布の $W_2$ 変化を接空間で等方化するという要請が，
noise covariance を一意に決める．

\subsection{座標不変性}

\begin{proposition}[潜在座標の取り替えに対する不変性]
\label{prop:coordinate}
  $\psi\colon\mathcal{Z}\to\widetilde{\mathcal{Z}}$ を微分同相とし，
  $\widetilde F:=F\circ\psi^{-1}$ とする．$G$ と $\widetilde G$ から
  定理~\ref{thm:canonical}の covariance をそれぞれ作ると，
  $\widetilde Z_t=\psi(Z_t)$ の covariance は
  \[
    D\psi\,\beta_tG^{-1}D\psi^{\mathsf T}
    =\beta_t\widetilde G^{-1}
  \]
  となる．対応する幾何学的 drift も含めれば，二つの座標系で構成した process は
  同一の decoder 分布過程 $K_{Z_t}$ を与える．
\end{proposition}

\begin{proof}
  $\widetilde G=(D\psi^{-1})^{\mathsf T}G(D\psi^{-1})$ を逆行列にすれば
  covariance の式を得る．drift を含む主張は次節の generator が
  Riemann 計量と確率測度だけから定義されることによる．
\end{proof}

標準 LDM の $I_d$ は一般の $\psi$ で $I_d$ に移らない．したがって
命題~\ref{prop:coordinate}は，通常の latent noising と提案法を分ける
直接検証可能な予測を与える．

\section{VAE prior に可逆な forward process}
\label{sec:forward}

\subsection{generator と It\^o SDE}

単なる Riemannian Brownian motion は一般に $\mathcal{N}(0,I_d)\d z$ を
不変分布にもたない．そこで prior 測度 $\pi$ 自体を幾何学的構成に含める．

\begin{definition}[prior-reversible Wasserstein latent diffusion]
\label{def:generator}
  滑らかな関数 $f$ に対して
  \[
    \boxed{
    \mathcal{L}_t f
    :=\frac{\beta_t}{2p_\pi}
      \partial_i\!\left(p_\pi G^{ij}\partial_jf\right)
    }
    \tag{3}
  \]
  と定める．Einstein の規約により重複する添字について和をとる．
\end{definition}

(3) に対応する It\^o SDE は
\[
  \d Z_t^i=b_\pi^i(Z_t,t)\d t
       +\sqrt{\beta_t}\,[G(Z_t)^{-1/2}]^i{}_a\d W_t^a,
  \tag{4}
\]
\[
  \boxed{
  b_\pi^i(z,t)
  =\frac{\beta_t}{2}
    \left\{\partial_jG^{ij}(z)+G^{ij}(z)\partial_j\log p_\pi(z)\right\}.
  }
  \tag{5}
\]
ここで $G^{-1/2}$ は $G^{-1/2}(G^{-1/2})^{\mathsf T}=G^{-1}$ をみたす
任意の滑らかな frame でよい．

\begin{proposition}[prior の不変性と可逆性]
\label{prop:reversible}
  $\pi(\d z)=p_\pi(z)\d z$ は (3) の不変分布である．さらに滑らかな
  $f,g$ に対して
  \[
    \int f\,\mathcal{L}_tg\,\d\pi
    =-\frac{\beta_t}{2}\int
      \langle\nabla_Gf,\nabla_Gg\rangle_G\,\d\pi
    =\int g\,\mathcal{L}_tf\,\d\pi
  \]
  であり，process は $\pi$ に関して可逆である．
\end{proposition}

\begin{proof}
  (3) を $p_\pi\d z$ に関して部分積分すればよい．$f=1$ とおくと
  $\int\mathcal{L}_tg\d\pi=0$ だから不変性が従う．
\end{proof}

\subsection{確率測度上の Wasserstein 勾配流}

(3) は Riemann 幾何の記法では
\[
  \mathcal{L}_tf
  =\frac{\beta_t}{2}
   \left\{\Delta_Gf+
     \langle\nabla_G\log q_\pi,\nabla_Gf\rangle_G\right\}
  \tag{6}
\]
と書ける．$r_t$ を $Z_t$ の $\d\vol_G$ に関する密度とすると，
Fokker--Planck 方程式は
\[
  \partial_tr_t
  =\frac{\beta_t}{2}\operatorname{div}_G
    \left(r_t\nabla_G\log\frac{r_t}{q_\pi}\right).
  \tag{7}
\]

\begin{proposition}[二層目の Wasserstein 構造]
\label{prop:gradient-flow}
  (7) は，ground metric を $G$ とする確率測度空間
  $\Pp2(\mathcal{Z},G)$ における
  \[
    \mathrm{KL}(r\,\d\vol_G\Vert\pi)
  \]
  の最急降下流である．時刻は $\beta_t/2$ で再尺度化される．
\end{proposition}

これは Fokker--Planck 方程式の Wasserstein 勾配流解釈
\cite{jordan1998} を $(\mathcal{Z},G)$ に適用したものである．
本稿では二種類の Wasserstein 幾何が入れ子になる．

\begin{itemize}
  \item $G$ を定める\textbf{ミクロな $W_2$}：各 decoder 分布 $K_z$ 間の距離．
  \item (7) を定める\textbf{マクロな $W_2$}：decoder 分布の族上にある
    確率法則 $\rho_t$ 間の距離．
\end{itemize}

\section{第二基本形式は diffusion drift になる}
\label{sec:curvature-drift}

$F(\mathcal{Z})\subset H$ を Euclid 空間内の immersed submanifold とみなす．
\[
  P:=J_FG^{-1}J_F^{\mathsf T},
  \qquad
  B_{ij}:=(I_{2n}-P)\partial_i\partial_jF
\]
を接空間への射影と第二基本形式とし，平均曲率ベクトルを
\[
  \mathcal{H}(z):=G^{ij}(z)B_{ij}(z)
\]
と定める．この符号規約では $\mathcal{H}=\Delta_GF$ である．

\begin{theorem}[decoded process の extrinsic 表示]
\label{thm:extrinsic}
  $Z_t$ が (4) に従い $Y_t=F(Z_t)$ とする．局所的に $F$ が embedding である
  範囲では，$Y_t$ は
  \[
    \boxed{
    \d Y_t
    =\frac{\beta_t}{2}
       \left\{\mathcal{H}(Z_t)
       +J_F(Z_t)\nabla_G\log q_\pi(Z_t)\right\}\d t
     +\sqrt{\beta_t}\,P(Z_t)\d W_t^{H}
    }
    \tag{8}
  \]
  と同じ generator をもつ．$W^H$ は $\R^{2n}$ 上の Brownian motion である．
\end{theorem}

\begin{proof}
  (6) を $F$ の各座標関数へ作用させる．等長 immersion の標準公式
  $\Delta_GF=\mathcal{H}$ より drift の法成分が $\beta_t\mathcal{H}/2$ となる．
  prior drift は微分 $J_F$ によって接空間へ写る．martingale 部分の共分散は
  定理~\ref{thm:canonical}より $\beta_tP$ であり，$P^2=P$ なので
  $\sqrt{\beta_t}P\d W^H$ と表せる．
\end{proof}

式 (8) は本稿における曲率の役割を明確にする．接空間へ射影した noise だけでは
It\^o の意味で曲がった部分多様体上の Brownian motion にならず，
平均曲率 drift が必要である \cite{hsu2002}．しかも $\mathcal{H}$ は
$F$ の二階微分から計算できる．曲率は生成後の診断量ではなく，forward process の
一部である．

\section{逆時間過程と自然な relative score}
\label{sec:score}

$p_t$ を $Z_t$ の Lebesgue 密度とし，natural relative score を
\[
  s_t^*(z)
  :=\nabla_G\log\frac{p_t(z)}{p_\pi(z)}
  =G(z)^{-1}\nabla_z\log\frac{p_t(z)}{p_\pi(z)}
  \tag{9}
\]
と定める．これは座標微分としての covector ではなく，潜在多様体上の vector field
である．

\begin{proposition}[逆時間 drift]
\label{prop:reverse}
  $Y_s:=Z_{T-s}$ とする．通常の time-reversal の正則性条件
  \cite{haussmann1986} のもとで，$Y_s$ の drift は
  \[
    \boxed{
      \bar b^i(z,s)
      =b_\pi^i(z,T-s)+\beta_{T-s}\,[s_{T-s}^*(z)]^i
    }
    \tag{10}
  \]
  であり，noise covariance は $\beta_{T-s}G^{-1}$ のままである．
\end{proposition}

\begin{proof}
  $a^{ij}=\beta_tG^{ij}$ とする．一般の It\^o diffusion の逆時間 drift は
  \[
    -b^i+\partial_ja^{ij}+a^{ij}\partial_j\log p_t
  \]
  である．(5) を代入して整理すると
  \[
    \frac{\beta_t}{2}
    (\partial_jG^{ij}+G^{ij}\partial_j\log p_\pi)
    +\beta_tG^{ij}\partial_j\log(p_t/p_\pi)
  \]
  となり，(10) を得る．
\end{proof}

\subsection{transition kernel を要しない score matching}

vector field $s_\vartheta(z,t)$ で (9) を近似する．prior に関する divergence を
\[
  \operatorname{div}_\pi s
  :=\frac{1}{p_\pi}\partial_i(p_\pi s^i)
\]
と定める．
以下は古典的 score matching \cite{hyvarinen2005} を prior-relative な
Riemann 幾何へ書き直した目的関数である．

\begin{proposition}[relative Riemannian score matching]
\label{prop:score-matching}
  時刻 $t$ を固定し，
  \[
    \mathcal{J}_t(\vartheta)
    :=\E_{Z\sim p_t}
      \left[
        \frac12s_\vartheta(Z,t)^{\mathsf T}G(Z)s_\vartheta(Z,t)
        +\operatorname{div}_\pi s_\vartheta(Z,t)
      \right]
    \tag{11}
  \]
  とする．境界項が消え，関数クラスが十分豊かなら，(11) の最小化解は
  $s_\vartheta=s_t^*$ である．
\end{proposition}

\begin{proof}
  $r=p_t/p_\pi$ とおく．$\pi$ に関する部分積分から
  \[
    -\E_{p_t}\langle s,\nabla_G\log r\rangle_G
    =\E_{p_t}[\operatorname{div}_\pi s]
  \]
  である．したがって (11) は
  $\frac12\E_{p_t}\norm{s-s_t^*}_G^2$ と $\vartheta$ に依存しない定数の和になる．
\end{proof}

重要なのは
\[
  s_\vartheta^{\mathsf T}Gs_\vartheta
  =\norm{J_Fs_\vartheta}^2
\]
である．したがって score loss の metric norm は decoder の JVP 一回で評価でき，
$G$ や $G^{-1}$ を行列として作る必要がない．divergence は Hutchinson 推定を用いた
sliced score matching \cite{song2020} で近似できる．forward trajectory の生成は
依然として $G^{-1/2}$ を要するため，その近似は第\ref{sec:computation}節で論じる．

\section{曲率による step 誤差の証明書}
\label{sec:certificate}

第二基本形式を双線形写像
$B(u,v)=u^iv^jB_{ij}$ とみなし，
\[
  \Lambda(z)
  :=\sup\left\{\norm{B(u,v)}:
      \norm{u}_{G(z)}=\norm{v}_{G(z)}=1\right\}
\]
と定める．$\Lambda$ は decoder manifold の最大の外在的曲がりを測る．

\begin{theorem}[geodesic step の decoded distortion]
\label{thm:chord}
  $\gamma\colon[0,L]\to\mathcal{Z}$ を単位速度の $G$-測地線とする．
  $\gamma$ に沿って
  $\norm{B(\dot\gamma,\dot\gamma)}\leq\Lambda$ かつ $\Lambda L\leq\pi$ ならば
  \[
    \frac{2}{\Lambda}\sin\frac{\Lambda L}{2}
    \leq W_2(K_{\gamma(0)},K_{\gamma(L)})\leq L
  \]
  であり，特に
  \[
    \boxed{
    0\leq L-W_2(K_{\gamma(0)},K_{\gamma(L)})
    \leq\frac{\Lambda^2L^3}{24}.
    }
    \tag{12}
  \]
\end{theorem}

\begin{proof}
  $c=F\circ\gamma$ とおく．$F$ は等長 immersion なので $\norm{\dot c}=1$ であり，
  測地線方程式から $\ddot c=B(\dot\gamma,\dot\gamma)$ となる．したがって $c$ は
  曲率が $\Lambda$ 以下の長さ $L$ の Euclid 曲線である．Schur 型の弦長評価より
  $\norm{c(L)-c(0)}\geq2\Lambda^{-1}\sin(\Lambda L/2)$ を得る．
  上界は弦長が曲線長以下であることによる．最後に
  $\sin x\geq x-x^3/6$ を用い，事実~\ref{fact:gaussian-w2}を適用する．
\end{proof}

geodesic random walk の一 step を
\[
  z^+=\operatorname{Exp}_z(\sqrt{\beta_th}\,\xi),
  \qquad \xi\sim\mathcal{N}(0,I_{T_z\mathcal{Z}})
\]
とする．この step の内在長は
$L=\sqrt{\beta_th}\norm{\xi}_G$ なので，(12) は
\[
  L-W_2(K_z,K_{z^+})
  \leq
  \frac{\Lambda^2}{24}(\beta_th)^{3/2}\norm{\xi}_G^3
  \tag{13}
\]
を与える．よって許容誤差を固定すれば，$\Lambda$ の大きい領域で $h$ を小さくする
曲率適応 solver が得られる．これは単なる numerical heuristic ではなく，
decoder 分布上の $W_2$ distortion を直接制御する．

\section{Schr\"odinger bridge への拡張}
\label{sec:bridge}

有限時刻 $T$ で $\rho_{\mathrm{data}}$ と $\pi$ の endpoint を厳密に合わせるには，
第\ref{sec:forward}節の process を参照過程 $R_G$ とする
Schr\"odinger bridge
\[
  Q^*
  =\arg\min_{Q:\,Q_0=\rho_{\mathrm{data}},\,Q_T=\pi}
    \mathrm{KL}(Q\Vert R_G)
  \tag{14}
\]
を考えればよい．これは path-space 上の entropic optimal transport であり，
通常の diffusion model と有限時間 OT を結ぶ \cite{debortoli2021,tong2024}．

$\beta_t\equiv1$ とし，generator 全体を $\varepsilon$ 倍して
$\varepsilon\to0$ とすると，$\varepsilon$ に依存する全体係数を除いた
(14) の動的 cost の主要部は
\[
  \int_0^T\int_{\mathcal{Z}}
    \frac12\norm{v_t(z)}_{G(z)}^2\rho_t(z)\,\d z\,\d t
  =\int_0^T\int_{\mathcal{Z}}
    \frac12\norm{J_F(z)v_t(z)}^2\rho_t(z)\,\d z\,\d t
  \tag{15}
\]
となる．右辺は decoder 分布の瞬間的 $W_2$ 速度の二乗である．
したがって (14) は潜在座標の移動距離ではなく，decoder が表す分布を運ぶ cost を
最小化する stochastic generative model である．

本稿では (3)--(11) の prior-reversible diffusion を主モデルとし，
(14) はより強い有限時間版として位置づける．最初から bridge solver と
metric approximation を同時に導入すると誤差源を分離できないため，
実験ではまず reversible model を検証し，その後に bridge 化する．

\section{計算方法}
\label{sec:computation}

\subsection{matrix-free な metric 演算}

任意の $v\in\R^d$ に対して
\[
  Gv=J_F^{\mathsf T}(J_Fv)
\]
だから，JVP と VJP を一回ずつ用いれば $Gv$ を計算できる．したがって
$G^{-1}u$ は共役勾配法，$G^{-1/2}\xi$ は Lanczos 法で近似できる．
一方，$\norm{s}_G^2=\norm{J_Fs}^2$ と
$B(u,v)=(I-P)\partial^2F[u,v]$ は，行列を明示せず評価できる．

\begin{algorithm}[t]
\caption{曲率適応 Wasserstein latent reverse step（概念形）}
\label{alg:sampler}
\medskip\hrule\medskip
\noindent\textbf{入力：}decoder $F$，score $s_\vartheta$，現在点 $z$，時刻 $t$，
基準 step $h_0$，許容 distortion $\epsilon$\\
\noindent\textbf{出力：}一 step 前の潜在点
\medskip\hrule\medskip
\begin{algsteps}
  \item JVP/VJP oracle から $Gv=J_F^{\mathsf T}J_Fv$ を定義する
  \item 方向付き二階微分から $\widehat\Lambda(z)$ を推定する
  \item (13) の右辺が $\epsilon$ 以下になるよう $h\leq h_0$ を選ぶ
  \item CG/Lanczos または近似 frame により $b_\pi$ と $G^{-1/2}\xi$ を評価する
  \item (10) の reverse drift と covariance $\beta_tG^{-1}$ で一 step 更新する
  \item 必要なら decoder 出力の $W_2$ 変化を測り step を reject / 縮小する
\end{algsteps}
\medskip\hrule
\end{algorithm}

\subsection{高次元 latent への三段階近似}

画像 LDM の latent 次元では exact solve を各 step で行うのは高価である．
そこで次の三段階を比較する．

\begin{enumerate}
  \item \textbf{conformal approximation:}
    $a=(d/\operatorname{tr}G)I$．decoded 変化の総量だけを $\beta_td$ に合わせる．
  \item \textbf{diagonal / block approximation:}
    $a\approx\operatorname{diag}(G)^{-1}$，または空間 patch ごとの block inverse．
    $\operatorname{diag}(G)$ は Hutchinson 推定できる．
  \item \textbf{metric distillation:}
    convolutional linear operator $L_\eta(z)$ に
    \[
      L_\eta(z)^{\mathsf T}G(z)L_\eta(z)\approx I
    \]
    を学習させ，sampling 時は $G^{-1/2}$ を $L_\eta$ で置き換える．
\end{enumerate}

exact，conformal，diagonal，distilled の順に，座標不変性と計算量の trade-off がある．
近似法が exact model の性質をどこまで保持するか自体を ablation の対象にする．

\section{実験計画と反証条件}
\label{sec:experiments}

本稿の主張は生成例の見た目だけでなく，局所量によって反証可能である．

\subsection{段階 I：既知の曲率をもつ synthetic decoder}

潜在次元 $d=2$ とし，放物面型・鞍型の $F$ を用いる．真の $G,B,\Lambda$ が
閉形式で得られるため，次を検証する．

\begin{enumerate}
  \item Euclid noise の decoded 変化率が $\beta\operatorname{tr}G(z)$ に一致するか．
  \item canonical noise の変化率が $\beta d$ に一様化されるか．
  \item 平均曲率 drift を除いたときにどの程度 manifold bias が生じるか．
  \item (12)--(13) が実測 step error を上から抑えるか．
  \item 非線形な座標変換の前後で decoded path law が一致するか．
\end{enumerate}

\subsection{段階 II：低次元 VAE}

MNIST，Fashion-MNIST，必要なら小規模な連続科学データで，
$d\in\{2,8,16,32\}$ の $C^2$ 級 VAE を学習する．decoder variance を固定せず，
$\sigma(z)$ を意味のある aleatoric uncertainty として学習する．baseline は

\begin{itemize}
  \item Euclidean latent diffusion，
  \item conformal / diagonal / exact Wasserstein latent diffusion，
  \item exact model から平均曲率 drift を除いたもの，
  \item 曲率適応 step を固定 step に置き換えたもの
\end{itemize}

とする．評価量は FID や precision/recall に加え，

\begin{itemize}
  \item $z$ ごとの decoded $W_2$ corruption rate の変動係数，
  \item $\operatorname{tr}G$ または $\det G$ の上下 quartile 別の生成誤差，
  \item 座標変換前後の decoded sample distribution の距離，
  \item $\Lambda$ と局所 sampler error の相関，
  \item 同一品質に必要な neural function evaluations
\end{itemize}

を用いる．特に座標変換実験は，標準 LDM にはない
命題~\ref{prop:coordinate}を直接検証する．

\subsection{反証条件}

次のいずれかが成立すれば，提案法の主要仮説は支持されない．

\begin{enumerate}
  \item 学習済み VAE 上で $\operatorname{tr}G$ の変動が小さく，標準 noising の
    decoded corruption が既にほぼ一様である．
  \item corruption の一様化が score 学習，生成品質，あるいは high-distortion
    領域の誤差を改善しない．
  \item 平均曲率 drift と $\Lambda$-adaptive step の効果が計算誤差以下である．
  \item metric approximation の追加計算量が，削減される sampling step 数を上回る．
\end{enumerate}

\section{関連研究と新規性の境界}
\label{sec:related}

\paragraph{潜在空間の引き戻し幾何．}
確率的 decoder の期待引き戻し計量
$J_m^{\mathsf T}J_m+J_\sigma^{\mathsf T}J_\sigma$ は
Arvanitidis ら \cite{arvanitidis2018} が導いた．Fisher--Rao 計量を
decoder 分布から引き戻す一般的枠組みも提案されている
\cite{arvanitidis2022}．本稿と最も直接に重なるのは
Roy and Hauberg \cite{roy2022} であり，VAE decoder 分布の Wasserstein metric を
潜在空間へ引き戻して geodesic を計算した．したがって $G$ 自体は本稿の新規性ではない．
本稿は $G^{-1}$ が decoded $W_2$-isotropic diffusion の一意な covariance になること，
prior-reversible drift，relative score，曲率適応離散化までを導く．

\paragraph{Riemannian diffusion と flow matching．}
De Bortoli ら \cite{debortoli2022} は既知の Riemann 多様体上へ score-based model を
拡張した．Metric Flow Matching \cite{kapusniak2024} と Pullback Flow Matching
\cite{dekruiff2024} は data-dependent metric または pullback geometry に沿う
deterministic flow を学習する．本稿は VAE decoder の条件付き\emph{分布}間の
$W_2$ を ground metric とし，stochastic noising の局所的意味を一様化する点，
および第二基本形式を drift と誤差制御に使う点で異なる．

\paragraph{分布を一点として生成するモデル．}
Wasserstein Flow Matching \cite{haviv2026} は Gaussian や point cloud のように
各データ点自体が確率分布である場合の flow matching を扱う．本稿でも $K_z$ を
一点とみなすが，任意の Gaussian 族を生成するのではなく，固定 VAE が定める
低次元部分多様体 $F(\mathcal{Z})$ 上で aggregated posterior を学習し，
既知の VAE prior へ接続する．

\paragraph{diffusion model の幾何．}
Karczewski ら \cite{karczewski2026} は，data と同次元の probability-flow ODE
decoder に対する pullback geodesic が data 空間の直線へ写ることを示した．
本稿は $d<2n$ の VAE bottleneck と stochastic decoder 分布を対象とするため，
この全次元での退化は生じない．一方，Rao ら \cite{rao2026} の
decoder distortion と memorization の関連は，本稿が修正しようとする
non-uniform noising に経験的動機を与える．

\section{限界}
\label{sec:limitations}

\paragraph{対角 Gaussian decoder．}
閉形式と平坦な周囲空間は対角 Gaussian に依存する．一般共分散では
Bures--Wasserstein 幾何の周囲曲率が現れる．ただし
$\operatorname{tr}(Ga)$ による局所変化率と canonical covariance $G^{-1}$ の原理は，
滑らかな正定値 pullback metric に対してそのまま成立する．

\paragraph{画像における意味のある ground cost．}
pixel 空間の Gaussian $W_2$ は $\ell_2$ 的であり，知覚的意味を完全には表さない．
まず ground cost が妥当な低次元データで原理を検証すべきである．画像へ進む場合は，
固定された知覚特徴への pushforward 分布で metric を定める拡張が必要になるが，
Gaussian 閉形式は近似になる．

\paragraph{実用 VAE の variance．}
多くの画像 autoencoder は decoder variance を固定または無視する．その場合
$J_\sigma=0$ となり，本稿の metric は決定論的 decoder の Euclid pullback に退化する．
分散チャネル固有の利点を主張するには，$\sigma(z)$ が校正された VAE を学習する必要がある．

\paragraph{rank，単射性，完備性．}
$J_F$ の最小特異値が小さい場所では $G^{-1}$ が不安定になる．また immersion は
大域的単射性を保証せず，異なる latent が同じ decoder 分布を表す可能性がある．
理論は full-rank な局所 chart で成立するが，大域的生成には高確率領域での embedding，
または同値な latent をまとめる quotient の扱いが必要である．

\paragraph{計算量．}
exact $G^{-1/2}$，$\partial_jG^{ij}$，$\Lambda$ の評価は標準 LDM より高価である．
本稿の価値は，追加計算を生成品質または step 数の減少で回収できる場合に限られる．
第\ref{sec:experiments}節の NFE と wall-clock の比較を省略してはならない．

\paragraph{有限時間の prior mismatch．}
命題~\ref{prop:reversible}は $\pi$ の不変性を保証するが，任意の初期分布が
有限時刻で $\pi$ に近づく速さまでは保証しない．収束率には $G$ と $\pi$ に関する
Poincar\'e 不等式や log-Sobolev 不等式などが必要である．実験では終端 mismatch を
測定し，大きい場合は第\ref{sec:bridge}節の endpoint-constrained bridge を用いる．

\section{結論}

latent diffusion の noise は，潜在座標ではなく decoder が表す対象に対して
定義されるべきである．対角 Gaussian decoder では $W_2$ が
$F=(m,\sigma)$ の Euclid 距離に一致するため，この原理から
$G=J_F^{\mathsf T}J_F$ と canonical covariance $G^{-1}$ が得られる．
標準 Euclid noise の decoded 変化率は $\beta\operatorname{tr}G(z)$ で非一様だが，
提案法はそれを $\beta d$ に一様化する．prior-reversible generator は
この局所設計を大域的な forward process にし，第二基本形式は平均曲率 drift と
step distortion の証明書を同時に与える．

したがって最適輸送は損失関数として後付けされるのではない．
noise covariance，drift，score，step size の設計原理そのものになる．
