# 最適輸送 3D ビューア

[0,1]² 上の離散測度 μ, ν の間のエントロピー正則化最適輸送を Sinkhorn 反復（対数領域）で解き、
測度・輸送計画・変位補間 μ_t を three.js で立体表示する単一ファイルの Web アプリ。

```sh
make ot-viz   # http://localhost:8765/ で開く
```

- 測度: プリセット（ガウス、2 峰、リング など）または床面への手描き
- Sinkhorn: ε と格子の大きさを変えて、⟨C, P^ε⟩ と周辺誤差を確認できる
- 表示: μ, ν, μ_t の曲面、輸送経路の弧、変位補間に沿って動く粒子、重心射影の矢印

定義と出典はアプリ内の「定義と出典」に記載している。
