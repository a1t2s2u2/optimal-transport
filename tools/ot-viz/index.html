定義と出典

離散測度． x1, …, xN を [0,1]² の n × n 格子点（N = n²）とし， μ = Σi ai δxi， ν = Σj bj δxj とする（a, b は確率ベクトル）．高さは各点の質量を幅 ≈ 格子間隔のガウス核でならしたものである．

コストと輸送計画． Cij = ‖xi − xj‖²， U(a, b) = { P ∈ ℝ+N×N : P𝟙 = a, P⊤𝟙 = b }．

エントロピー正則化． H(P) = −Σij Pij(log Pij − 1) として LCε(a, b) = minP∈U(a,b) ⟨C, P⟩ − εH(P)． その一意な解 Pε を Sinkhorn 反復（対数領域，ε を大きい値から目標値まで徐々に下げる）で求める． ε → 0 で ⟨C, Pε⟩ は LC(a, b) = W₂(μ, ν)² に収束する． Peyré–Cuturi, Computational Optimal Transport, 第4章．

変位補間． t ∈ [0, 1] に対し μt = Σij Pij δ(1−t)xi + t xj． P が最適輸送計画のとき，これは μ と ν を結ぶ W₂ の測地線である．ここでは P = Pε で近似している． R. J. McCann, A convexity principle for interacting gases, Adv. Math. 128 (1997).

重心射影． T(xi) = ai−1 Σj Pij xj． 各点から出る質量の行き先の平均で，床面上の矢印として描く．
