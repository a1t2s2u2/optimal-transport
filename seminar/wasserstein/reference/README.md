本編第3章「測度分解定理」では，接着補題で使う積空間上の形に限定し，
可測な確率測度の族と矩形上の積分公式の存在，および本質的一意性を一つの定理として述べた．
一般の写像による形，逆像への集中，一般の関数の積分公式は扱わない．
存在の証明は資料の構成方法に沿い，第1の空間が compact な場合に Radon–Nikodym 微分と
可算な稠密部分空間から Riesz の表現定理で測度を作る．一般の Polish 空間では
第1周辺分布の tightness を用い，各制限測度の第2周辺分布の
Radon–Nikodym 微分を重みとして分解を足し合わせる．
資料が符号付きの Radon–Nikodym（Corollary 4.6.3）を使う箇所は，
連続関数を正部分・負部分に分けて非負の場合だけで済ませた．

発表の中心は二つの準備定理の証明と，それらを用いた測度分解の構成・一意性である．
補助結果の証明は付録にまとめ，必要に応じて参照する．$C(K)$ の可分性は，
各半径で有限個の球を選び，距離から作った連続関数を和が $1$ になるように正規化して示す．
有理係数の有限線形結合だけで任意の連続関数を一様近似できるため，
Stone–Weierstrass の定理や一般の分割の定理を前提としない．
閉部分空間の Borel 集合の性質と，接着補題で使う直積空間の Borel 集合の性質にも証明を付けた．
一般の Polish 空間への拡張で必要な一つの確率測度の tightness は，
第2章で既に用いた Prokhorov の定理を一元集合 $\{\mu\}$ に適用して得る．
有限個の閉球による被覆からの直接証明も付録に残すが，これは補足であり，発表には必須としない．

同章の節「Radon–Nikodym の定理」では，零集合による絶対連続性の定義
（Folland (1999) §3.2）を使い，有限測度の密度の存在・一意性を証明する．
記号は北別府 p.57 に合わせ，可測空間を $(X,\Sigma)$，基準測度を $\mu$，
密度で表す測度を $\nu$ とし，$\nu(A)=\int_Af\,\d\mu$，$f=\d\nu/\d\mu$ と書く．
p.57 の ε–δ による定義との同値性は，付録「測度分解のための準備」に証明を置いた．
存在の証明は，資料の Lebesgue 分解定理（Theorem 4.6.1）の $L^2$ による構成を，
$\nu\ll\mu$ の場合に適用する．$\pi=\mu+\nu$ とおき，Hilbert 空間版 Riesz により
$\int g\,\mathrm{d}\nu=\int gh\,\mathrm{d}\pi$ を得て，$0\leq h\leq1$ の代表元を取る．
$B=\{h=1\}$ は $\mu$-零集合なので絶対連続性から $\nu(B)=0$ でもあり，
$G_n=\{0\leq h\leq1-1/n\}$ 上で割り算して $f=h/(1-h)$ を取り出す．
資料の $B=\{h\geq1\}$ は，代表元を選んだ後には $\{h=1\}$ と一致する．
Lebesgue 分解定理を独立して立てず，密度の構成と一意性を一つの証明にまとめた．
この一意性の議論は実数値の可積分関数に通用する形で示し，後の測度分解でも再利用する．
資料の Theorem 4.6.1 が有限または σ-有限の基準測度を扱うのに対し，
ここで述べる Radon–Nikodym の定理は Corollary 4.6.2 と同じ有限の場合である．
特に，証明中の指示関数と切り詰めた関数が $L^2(\pi)$ に属することを明記した．

同章の節「Riesz–Markov–Kakutani の表現定理」では，Rudin *Real and Complex Analysis* Theorem 2.14 の方針
（開集合の測度を汎関数の上限で定める）を compact 距離空間に特化し，
Carathéodory の定理を用いて証明した．可算劣加法性には，compact な部分を覆う
連続関数の和による上からの評価だけを使い，関数を厳密に分割する補題は用いない．
積分表示は開集合 $\{f>k/n\}$ の指示関数による下からの近似で示す．
両定理の主張は
[Arun Ram の講義ノート](https://math.soimeme.org/~arunram/Notes/RadonNikodymContent.html)
でも確認できる．

### 提供写真と本原稿の対応

上記8枚を照合した．本編第2章の Wasserstein 距離は Villani を基準とし，
第3章は北別府の測度分解の構成を，接着補題に必要な範囲に限定して用いる．

| 項目 | 北別府の提供資料 | 本原稿 |
| --- | --- | --- |
| RN の記号 | $(X,\Sigma)$，基準測度 $\mu$，対象の測度 $\nu$，密度 $f$ | 同じ記号を使用し，$f=\d\nu/\d\mu$ を明記 |
| 絶対連続性 | ε–δ 条件を定義とし，零集合による条件との同値性を示す | 零集合による条件を定義とし，ε–δ 条件との同値性は付録で証明 |
| RN の証明 | $L^2$ 上の表現定理から Lebesgue 分解定理を経る | 同じ $L^2(\mu+\nu)$ の構成を絶対連続の場合に絞り，密度を直接構成 |
| Hilbert 空間版 Riesz | p.56 で引用．提供写真にこの表現定理自体の証明はない | 任意の有限測度に対する $L^2$ の完備性とともに，付録に証明を補う |
| 測度分解の主張 | Borel 可測写像 $T:X\to Y$ に沿う分解，逆像への集中と積分公式 | 積空間上の分布 $\pi$ を第2変数に沿って分解し，矩形上の積分公式と本質的一意性を示す |
| 測度分解の主要な記号 | $\pi,\nu,\nu_f,l_f,m_y,\lambda_y$ | 同じ記号を使用 |
| 空間・関数族・共通の例外集合 | $X,Y$，$C\subset C(X)$，$Y_C$ | 本編の記法に合わせて $\mathcal{X},\mathcal{Y}$，compact な場合は $K$，$\mathcal{C}\subset C(K)$，$\mathcal{Y}\setminus N$ |
| 指示関数・像測度 | $\chi_A$，$T_\sharp\mu$ | 本編の記法に合わせて $\mathbf{1}_A$，$\mu\circ T^{-1}$ |
| 密度から汎関数への構成 | 符号付きの RN を用い，可算な関数族上で共通の零集合を除いてから延長 | 非負の場合の RN と正部分・負部分を用いる．共通の零集合上の値を先に定め直してから延長 |
| Riesz–Markov–Kakutani | 提供写真では正の線形汎関数に適用して分解測度を得る | 必要な compact 距離空間の場合を独立した定理とし，外測度からの証明を補う |
| 一般の場合への拡張 | Corollary 5.1.19 により $T$ が連続となる互いに素な compact 集合に分ける | 積空間の場合に限定しているので，Prokhorov から得る compact 集合の差 $E_n$ に制限し，周辺分布の密度を重みに足し合わせる |
| 一意性の仕上げ | 可算な連続関数族の積分値の一致を使う | 可算な Borel 生成 $\pi$-系上の一致を使う |

第3章の導入と各節の冒頭でも，原資料を特殊化した範囲と，別証明・補足証明を用いる箇所を明示している．

## 別リポジトリ `seminar` の関数解析の原稿

ユーザー提供の [seminar リポジトリ](https://github.com/a1t2s2u2/seminar) の
`chapters/02_Lp_space.tex`（参照時のコミット `b717043`）を確認した．
Hilbert 空間版 Riesz という名称の独立した定理はないが，次の結果がある．

- `thm:riesz-fischer`：$L^p$ の完備性．
- `thm:Lp-dual-representation`：$L^p$ の双対表現．$p=2$ が $L^2$ 上の表現に対応する．
- `thm:projection-lemma`，`thm:orthogonal-decomposition`：Hilbert 空間の最小ノルム元の存在と直交分解．

同原稿の $L^p$ は Euclid 空間上の Lebesgue 測度に関するものなので，双対表現をそのまま
任意の測度 $\pi=\mu+\nu$ に引用するのではなく，必要な議論を本原稿の付録に補った．
完備性は $p=2$ の場合に絞り，差のノルムが可算和可能な部分列を取って証明する．
Hilbert 空間版 Riesz は，$C=\{u\mid L(u)=1\}$ における最小ノルム元を中線定理から構成し，
$L$ の核との直交性から表示元を得る．これは射影の補題の証明を必要な集合 $C$ に用いたもので，
一般の射影定理や直交分解定理を独立した前提にしない．
いずれも Radon–Nikodym の定理を用いずに証明している．
